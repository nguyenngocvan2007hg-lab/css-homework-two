# Homework Two — Advanced Selectors and Display

Mở index.html bằng trình duyệt để xem bài. Ba trang dùng chung css/style.css.

Các thay đổi:
- Mỗi trang có liên kết Skip to Main Content dẫn đến main-content.
- Ảnh chú chó nằm trong nav; nav dùng inline-block và rộng 80%; nav img rộng 10%.
- Quy tắc li cũ được giữ trong chú thích CSS; danh sách điều hướng bố trí bằng flex trên ul.
- Neighborhood dùng .grid gồm hai cột 40%, ảnh .grid img rộng 100%.
- Parks dùng .flex, cho phép xuống hàng, ảnh rộng 220px.

Trước khi nộp:
1. Mở cả ba trang, kiểm tra liên kết và ảnh.
2. Dùng phím Tab chọn Skip to Main Content, nhấn Enter để đến nội dung chính.
3. Tạo repository riêng cho bài 2 và tải NỘI DUNG thư mục này lên.
4. Bật GitHub Pages từ main, /(root).
5. Kiểm tra từng URL bằng WAVE và W3C Nu HTML Checker. Các kiểm tra trực tuyến này chưa được chạy cho bản bài 2.
6. Nộp URL GitHub Pages bài 2 và hoàn thành ba lượt đánh giá bạn học.

Chưa có ảnh giao diện mẫu của bài 2 để đối chiếu chính xác cách căn chỉnh.
